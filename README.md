OOChat - 基于 C++/Qt 的即时通讯系统
开发环境：Qt5.14.2
数据库：MySQL (服务端) / SQLite (客户端本地缓存)

基础社交：用户注册、登录及个人资料修改。好友/群组的模糊搜索与精确查找。好友申请的发送、接收与状态处理（接受/拒绝）。
即时通讯：实时私聊与群聊消息推送。离线消息自动拉取。
文件传输：9998 9999端口文件传输系统，支持文件上传与下载。
管理功能：好友备注、删除好友、退出/解散群组。
服务器MySql配置在dbmanager.cpp内修改。
